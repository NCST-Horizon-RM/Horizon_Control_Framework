# 平移、旋转功率分配

## 输入与输出

每个 `Power_Motion_Node_t` 对应一个真实电机，包含模型、当前实际电机转速（RPM）、平移电流指令、旋转电流指令和电流指令绝对值上限。两个指令与 `max_cmd` 都使用原始控制单位，例如 M3508 的 raw，而不是安培。

电机最终指令 = 平移指令 × translation_scale + 旋转指令 × rotation_scale。

所有电机共用两个比例，范围均为 0～1；平移 X/Y 不分别缩放。必须提供同一时刻的反馈；状态对象不能在节点间重复。回调不涉及内存分配，也不依赖底盘运动学。

返回的 `Power_Motion_Result_t` 包含两个保留比例、请求功率、分配后功率以及状态。最终电流写入各节点的 `state->limited_cmd`，合成的原始请求写入 `state->original_cmd`。

## 分配策略

`Power_Ctrl_Allocate_Motion_With_Priority()` 通过 `POWER_PRIORITY_TRANSLATION` 或 `POWER_PRIORITY_ROTATION` 选择优先分量。原接口 `Power_Ctrl_Allocate_Motion()` 保持默认平移优先。

底盘在跟随模式选择旋转优先，小陀螺及其他运行模式选择平移优先。每周期按当前模式选择，两个比例的字段含义始终不变。


1. 完整请求满足功率和所有电机电流上限时直接放行。
2. 固定优先分量比例为 1，寻找可执行的最大次优先分量比例。
3. 如果上一步没有可行解，先关闭次优先分量，寻找可执行的最大优先分量比例，再在此比例下补充次优先分量。

旋转优先仍受总功率和每轮电流上限约束，不意味着功率不足时能无条件维持跟随速度。模式切换会立即切换优先级，没有额外比例平滑。

这是有界迭代的分阶段策略，不是完整二维全局最优化。存在电流相消时，可能有更好的混合解未被这些阶段搜索到。`POWER_MOTION_NO_FEASIBLE_CANDIDATE` 表示这些阶段没有找到可执行组合，不能解释为所有组合都不可行。此时输出零电流，并如实报告零电流下仍存在的模型损耗；该损耗可能高于允许功率，不能宣称已经满足功率上限。非法输入返回 `POWER_MOTION_INVALID_INPUT`，可访问的输出电流清零，结果功率不代表有效预测。

## 功率口径

每次用组合后的电流和实际轮速重新计算完整电机模型，保留平移、旋转交叉项，不要求电机参数相同或轮组对称。各轮预测功率取 `max(功率, 0)` 后求和，不用制动轮的负功率抵扣其他轮耗电。该保守口径在搜索和结果报告中一致。

每条搜索线上的功率是凸函数，但制动时不一定随保留比例单调增加。必要时先寻找功率最小点，再搜索右侧可行边界；电流上限提前约束搜索区间。循环次数固定有上限，但接入 1 kHz 控制前仍需测量目标 MCU 上的最坏执行时间。模型参数、实际功率裕量以及轮胎附着限制仍需要实车标定。

## 底盘接入步骤

1. 用 `Chassis_Force(cfg, ax, ay, 0, ...)` 生成平移电流数组。
2. 用另一个命令对象调用 `Chassis_Force(cfg, 0, 0, angular_acceleration, ...)` 生成旋转电流数组，避免覆盖平移结果。
3. 填写每轮实测 RPM、两个 raw 指令及 `max_cmd`（例如 16000）。
4. 调用运动分配接口，检查返回状态，再发送 `limited_cmd`。
5. 上游的二维加速度限幅也应保持向量方向；本接口无法恢复已经被 X/Y 独立截断的方向。

本接口限制瞬时电流及其预测功率，不自动改变速度目标，不保证轨迹直线度。长时间功率不足时，可以根据保留比例在上层平滑降低旋转速度目标；降低当前旋转电流并不能立即消除已有转速产生的损耗。
